# Welcome to 10KB Wiki

An ultra-lightweight wiki in a single HTML file. No server, no framework.

## How it works

1. Write **Markdown** files in `docs/`
2. Run `python build.py`
3. Open `wiki.html` — works with `file://`

## Features

- Zero dependencies — just Python 3 for build
- Works offline, dark/light auto theme
- Wiki links with `[[Page Name]]`
- Searchable sidebar, responsive

See the [[Getting Started]] guide.

## Markdown

| Feature | Syntax |
|---------|--------|
| Headings | `# H1` to `###### H6` |
| Bold | `**text**` |
| Italic | `*text*` |
| Strikethrough | `~~text~~` |
| Code | `` `code` `` |
| Images | `![alt](url)` |
| Links | `[text](url)` |
| Wiki links | `[[Page]]` |
| Lists | `- item` or `1. item` |
| Blockquotes | `> quote` |
| Tables | Pipe tables |
| Code blocks | Triple backticks |
| Horizontal rule | `---` |
